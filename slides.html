Fundamental Concept

The Binary World & Electrical Signals

How hardware converts raw electricity into binary computation

  • 0
    Logic 0 (LOW): 0 Volts (Ground). Switch is OPEN. No current flows through to the lamp.
  • 1
    Logic 1 (HIGH): +5V / +3.3V (Vcc). Switch is CLOSED. Current flows to power the bulb.
  • ⚡
    Transistors as Switches: Modern computer chips replace mechanical switches with billions of nanometer-scale MOSFET transistors.

Hardware Representation

A logic gate receives electrical input levels and produces an output determined by Boolean rules.

Basic Gate

AND Gate (Conjunction)

Equation: Y = A · B (A AND B)

  • ✔ The bulb turns ON ONLY when BOTH switches A and B are 1 (Closed).
  • ✔ Series Switch Analogy: Electricity must pass through switch A and then switch B to reach the bulb.
  • ✔ Real-world: Two-person security authorization.

Basic Gate

OR Gate (Disjunction)

Equation: Y = A + B (A OR B)

  • ✔ The bulb turns ON if AT LEAST ONE switch is 1.
  • ✔ Parallel Circuit Analogy: Current has two alternate paths to flow through to the bulb.
  • ✔ Output is 0 only when both inputs are 0.
  • ✔ Real-world: Car dome lamp when any door opens.

Basic Gate

NOT Gate (Inverter)

Equation: Y = Ā (NOT A)

  • ✔ Features only ONE single input and one output.
  • ✔ Inverts the input: 0 becomes 1 (bulb ON), 1 becomes 0 (bulb OFF).
  • ✔ The schematic triangle has an "Inversion Bubble" at its output point.
  • ✔ Real-world: Automatic nightlights and emergency systems.

Universal Gate

NAND Gate (NOT-AND)

Equation: Y = (A · B)̄

  • ⭐ An AND gate followed by a NOT bubble.
  • ⭐ The bulb remains LIT unless BOTH switches are ON (1, 1).
  • ⭐ Universal Property: Can construct any other logic function.
  • ⭐ Backbone of NAND Flash SSD storage!

Universal Gate

NOR Gate (NOT-OR)

Equation: Y = (A + B)̄

  • ⭐ An OR gate followed by an inversion bubble.
  • ⭐ The bulb lights up ONLY when BOTH switches are 0.
  • ⭐ If either switch turns ON, the bulb immediately goes OFF.
  • ⭐ Moon Mission: Apollo Guidance Computer (1969) used ~5,600 NOR gates.

Special Gate

XOR Gate (Exclusive OR)

Equation: Y = A ⊕ B = ĀB + AB̄

  • ✦ Bulb is LIT when inputs are DIFFERENT (one 0 and one 1).
  • ✦ Bulb is OFF when inputs are identical (both 0 or both 1).
  • ✦ Essential building block for Binary Adders (Half Adder & Full Adder).
  • ✦ Real-world: Staircase two-way light switch circuit!

Special Gate

XNOR Gate (Equivalence)

Equation: Y = (A ⊕ B)̄ = AB + ĀB̄

  • ✦ Bulb is LIT when inputs are EQUAL / IDENTICAL (both 0 or both 1).
  • ✦ Acts as an electronic 1-bit equality comparator.
  • ✦ Crucial in parity generators and error detection in RAM and networks.
