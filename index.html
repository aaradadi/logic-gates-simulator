قواعد الجمع الثنائي في المعالج: Binary Addition Rules:

  • 0 + 0 = 0 ➔ Sum=0, Carry=0
  • 0 + 1 = 1 ➔ Sum=1, Carry=0 (مصباح Sum يضيء)
  • 1 + 0 = 1 ➔ Sum=1, Carry=0 (مصباح Sum يضيء)
  • 1 + 1 = 10₂ ➔ Sum=0, Carry=1 (مصباح Carry يضيء لنقل الخانة التالية!)
